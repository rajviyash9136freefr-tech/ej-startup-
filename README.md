# Luxury Real Estate & Architectural Residences

A modern, high-performance static website for showcasing luxury real estate and architectural properties.

## Project Structure

```text
├── images/             # All project images (property views, architectural galleries, hero)
├── index.html          # Main HTML, styling, and interactivity
├── vercel.json         # Vercel deployment configuration
├── .gitignore          # Git ignore rules
└── README.md           # Documentation
```

## Deployment on Vercel

This project is configured for deployment on [Vercel](https://vercel.com):

1. **Automatic Deployment (Recommended)**:
   - Import this GitHub repository (`https://github.com/rajviyash9136freefr-tech/ej-startup-`) into your Vercel Dashboard.
   - Framework Preset: `Other` (Static Site).
   - Click **Deploy**. Vercel will automatically build and deploy the site upon any push to `main`.

2. **CLI Deployment**:
   ```bash
   npx vercel
   # For production:
   npx vercel --prod
   ```
